# Default+

A dark color theme for Visual Studio Code, originally created as an Xcode Font & Color Theme.

Part of the [Default+ theme family](https://github.com/otaviocc/default-plus).

## Installation

1. Download the latest `default-plus-x.x.x.vsix` from the [Releases](https://github.com/otaviocc/default-plus-vscode/releases) page
2. Install it from the command line:

```
code --install-extension default-plus-x.x.x.vsix
```

3. Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`), run **Preferences: Color Theme**, and select **Default+**
